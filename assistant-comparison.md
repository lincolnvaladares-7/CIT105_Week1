## Purpose

This document compares the two categories of AI coding assistance introduced in Week 1: GitHub Copilot and Claude Code. The comparison focuses on how each tool supports software development and when each type of assistance is appropriate.

## GitHub Copilot

GitHub Copilot works mainly as an inline coding assistant. While a developer types code, Copilot can suggest the next line, complete a function, or generate a small block of code. This type of assistance is useful when the developer already knows what they are building and wants help writing code faster.

For a Week 1 Python exercise, Copilot could help complete a `print()` statement, an `if` statement, or a `for` loop. The developer remains responsible for reviewing the suggestion, testing the program, and deciding whether to accept or reject the generated code.

## Claude Code

Claude Code is used as an agentic coding assistant. Instead of focusing only on the current line of code, an agentic assistant can examine a larger repository, understand multiple files, propose a plan, and make coordinated changes across the project.

This type of assistance can be more appropriate for a larger task, such as reviewing a repository, updating several related files, or implementing a change that affects multiple parts of an application. According to the course instructions, Claude Code work for CIT 105 is completed during the scheduled AU AI Lab session.

## Comparison

GitHub Copilot and Claude Code support different parts of the development process. Copilot is useful for immediate, inline suggestions while a programmer is actively writing code. Claude Code is designed for broader tasks that may require understanding the repository and changing multiple files.

The important difference is the amount of responsibility given to the AI tool. With inline assistance, the developer controls the coding process line by line. With agentic assistance, the developer gives the assistant a larger task and must carefully review the proposed plan and resulting changes.

## Appropriate Use

I would use inline code suggestions for small and clearly defined coding tasks, such as completing syntax, creating a simple loop, or writing repetitive code. I would use an agentic coding assistant for a larger repository-level task that requires planning or coordinated edits across several files.

In both cases, AI-generated work should be reviewed and tested before it is accepted. The developer is responsible for understanding the code and confirming that it meets the assignment requirements.
